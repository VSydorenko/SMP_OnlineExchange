# Архітектура розширення СМП_ОнлайнОбменДанными

> Стан: чернетка бази знань, складена з коду версії сховища 78 (розширення 3.2.0.4)
> і опису автора. Шляхи до коду — відносно `СМП_ОнлайнОбменДанными/cfe/src/`.
> Позначки: **[код]** — підтверджено кодом; **[автор]** — зі слів автора;
> **[гіпотеза]** — висновок, що потребує перевірки.

## Що це

Підсистема **онлайн-обміну** між базами 1С (УНФ, BAS УНФ, BAS Бухгалтерія). На відміну
від КД2, яка вивантажує пакет змін за період, тут обмін **пооб'єктний**: кожен записаний або
проведений документ (і довідники, на які він посилається) одразу конвертується в JSON
і надсилається в базу-приймач через HTTP-сервіс.

Конвертація — **адаптована типова обробка КД2 `УниверсальныйОбменДаннымиXML`**: ті самі
ПКО/ПКС/ПКЗ, обробники подій і алгоритми, але правила лежать у довідниках бази, а замість
XML формується JSON. Правила діють з обох боків, як у КД2 **[автор][код]**.

Розширення встановлюється в **обидві** бази пари; кожна база може бути і джерелом, і
приймачем **[автор]**. Типові пари **[автор]**:

| Пара | Напрям |
|---|---|
| УНФ ↔ УТ | в обидва боки |
| УНФ → БП | БП лише приймає |

## Наскрізна схема

```
БАЗА-ДЖЕРЕЛО                                              БАЗА-ПРИЙМАЧ
─────────────                                             ─────────────
Документ: Записать/Провести
 └─ підписки СМП_РегистрацияДокумента*        (02)
     └─ правило реєстрації: тип + дата + СКД-відбір
         └─ РС СМП_ОчередьОбработкиДанных  [Новое]
             └─ ФЗ «формирование и отправка» (ключ: обмін/користувач)
                 └─ конвертація ПКО → масив JSON   (05)
                     └─ РС СМП_ОчередьИсходящихСообщений [Новое]
                         └─ POST gzip /hs/smp_exchange/data/{Ид} ──► HTTP-сервіс СМП_ОбменДанными (04)
                                                                       └─ РС СМП_ОчередьВходящихСообщений [Новое]
                                                                           ← 201 Created
                                                                       └─ ФЗ «обработка входящих»
                                                                           └─ конвертація: пошук/створення, запис,
                                                                              проведення (ОбменДанными.Загрузка)
Довідник: Записать
 └─ підписка СМП_РегистрацияСправочника — лише якщо елемент уже вивантажувався
```

## Глосарій

| Термін | Значення |
|---|---|
| Обліковий запис обміну | Елемент `Справочник.СМП_УчетныеЗаписиОбменов`. Один напрям: `ДляОтправки` або `ДляПолучения`. Двосторонній обмін — пара записів у кожній базі **[автор]** |
| Ідентифікатор обміну | Рядок `ИдентификаторОбмена`, яким пов'язуються запис-відправник і запис-приймач (частина URL) |
| ПКО / ПКС / ПКГС / ПКЗ | Правила конвертації об'єктів / властивостей / групи властивостей (табличні частини) / значень — як у КД2 |
| ПРД (тут) | «Правило реєстрації документа»: тип документа + `ДатаНачалаВыгрузкиДокументов` + СКД з відборами, з ТЧ `ОбъектыКВыгрузке` облікового запису |
| Повідомлення | Рядок у одній з черг (регістри відомостей); для вихідної/вхідної — один JSON-об'єкт |
| Нпп | Порядковий номер об'єкта всередині одного сеансу конвертації (з КД2) |
| Режим налагодження | `РежимОтладки` облікового запису: оброблені повідомлення не видаляються з черг, а лишаються зі статусом |

## Склад розширення (коротко)

- 9 довідників, 4 регістри відомостей, 7 обробок, 8 перелічень, 10 загальних модулів,
  1 HTTP-сервіс, 4 підписки на події, 1 підсистема, 1 роль. ~34 тис. рядків BSL, з них
  11,2 тис. — `DataProcessors/СМП_ОнлайнОбменКонвертацияОбъектов`.
- Префікс імен `СМП_` (`NamePrefix`), але частина об'єктів успадкувала імена з КД2 без
  префікса: `Алгоритмы`, `Конфигурации`, `Объекты`, `Свойства`, `Значения`,
  `ПравилаКонвертации*`, перелічення `Приложения`, `ТипыОбъектов`, `ПриоритетОбъектовОбмена`.
- Запозичено з основної конфігурації лише загальний модуль
  `ЗапретРедактированияРеквизитовОбъектовПереопределяемый` (перехоплення `&После`) і роль
  `ПолныеПрава`. Розширення спирається на БСП: `ОбщегоНазначения.ЗначениеРеквизитаОбъекта`,
  `ОбработкаОшибок.ПодробноеПредставлениеОшибки` тощо **[код]**.
- HTTP-клієнт — бібліотека «Коннектор» В. Бондаревського 2.6.0 (Apache 2.0), форк автора:
  `CommonModules/СМП_КоннекторHTTP`.
- Режим сумісності розширення — 8.3.17; призначення — `AddOn`.
