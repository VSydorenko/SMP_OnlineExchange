# 01. Модель даних

Шляхи — відносно `СМП_ОнлайнОбменДанными/cfe/src/`.

## Ієрархія налаштувань

```
Справочник.Конфигурации                 (опис метаданих конфігурації, як у КД2)
 └─ Справочник.Объекты                  (об'єкти метаданих)
     ├─ Справочник.Свойства             (реквізити, ТЧ, виміри…)
     └─ Справочник.Значения             (значення перелічень / предвизначені)

Справочник.СМП_УчетныеЗаписиОбменов     (обліковий запис = одна «конвертація» КД2 + транспорт)
 ├─ Справочник.ПравилаКонвертацииОбъектов   (ПКО)
 │   ├─ Справочник.ПравилаКонвертацииСвойств  (ПКС; групи = ПКГС)
 │   ├─ Справочник.ПравилаКонвертацииЗначений (ПКЗ)
 │   └─ Справочник.СМП_ПравилаСверки          (показники звірки, див. 07)
 └─ Справочник.Алгоритмы                     (алгоритми КД2)
```

Підлеглість задана власниками довідників (`<Owners>`) **[код]**. Обліковий запис посилається
на конфігурації реквізитами `Источник` і `Приемник` (`Справочник.Конфигурации`).

## Справочник.СМП_УчетныеЗаписиОбменов

Центральний об'єкт. Групи реквізитів **[код]**:

| Група | Реквізити | Призначення |
|---|---|---|
| Напрям | `НастройкаОбмена` (`СМП_НастройкиОбменов`: `ДляОтправки` / `ДляПолучения`), `ИдентификаторОбмена` | Запис-відправник у джерелі й запис-приймач у приймачі мають однаковий `ИдентификаторОбмена` |
| Транспорт | `СпособПодключения` (`СМП_ВидыТранспортовОбмена`: `ХттпСервис`, `Ком`, `Файл`), `ХттпСервисАдресПодключения`, `ИмяПользователя`, `ПарольПользователя`, `КомИмяСервера1СПредприятия`, `КомИмяИнформационнойБазыНаСервере1СПредприятия`, `ФайлКаталогОбмена` | Реалізовано лише HTTP; `Ком` і `Файл` — заготовки, не пріоритетні **[автор][код]** (див. [03](03-cherhy-i-transport.md)) |
| Реєстрація | `ДатаНачалаВыгрузкиДокументов`, ТЧ `ОбъектыКВыгрузке` (`ИмяОбъекта`, `ПолноеИмяОбъекта`, `Синоним`, `СКДДляОтборов` — ХранилищеЗначения, `СтрокаОтбор`) | Які документи і з якими відборами реєструються ([02](02-vidpravka.md)) |
| Конвертація | `Источник`, `Приемник`, `УдалятьСопоставленныеОбъектыВПриемникеПриИхУдаленииВИсточнике`, `ЗагружатьДанныеВРежимеОбмена`, `ЗаписыватьВИнформационнуюБазуТолькоИзмененныеОбъекты` | Параметри обробки конвертації |
| Обробники конвертації | 15 реквізитів `Алгоритм…` (`ПередВыгрузкойДанных`, `ПередКонвертациейОбъекта`, `ПослеЗагрузкиОбъекта` тощо) | Глобальні обробники подій КД2 рівня «Конвертация» |
| Службове | `РежимОтладки`, `Описание`, `Комментарий`, `ОписаниеВыгружаемыхДанных`, ТЧ `ОписаниеВыгружаемыхОбъектов` | ТЧ `ОписаниеВыгружаемыхОбъектов` використовує лише застарілий `СМП_JSONКонвертер` |

Модулі: `Catalogs/СМП_УчетныеЗаписиОбменов/Ext/{ObjectModule,ManagerModule}.bsl`,
форма `Forms/ФормаЭлемента` (1 093 рядки — редактор правил, СКД-відборів, алгоритмів).

## Регістри відомостей (черги)

Три черги мають **однакову структуру** **[код]**:

| Поле | Вид | Тип |
|---|---|---|
| `ИдентификаторПользователяИБ` | вимір | Строка — UUID користувача ІБ, що ініціював подію |
| `УчетнаяЗаписьОбмена` | вимір | СправочникСсылка.СМП_УчетныеЗаписиОбменов |
| `УникальныйИдентификатор` | вимір | Строка — UUID повідомлення |
| `ТаймШтамп` | вимір | Число — `ТекущаяУниверсальнаяДатаВМиллисекундах()`, ключ порядку обробки |
| `Статус` | ресурс | `СМП_СтатусыОбработкиСообщений` |
| `Данные` | реквізит | Строка (необмежена) |
| `ДатаДобавления`, `ДатаОбработки` | реквізити | Дата/час |
| `СообщениеОбОшибке` | реквізит | Строка |

| Регістр | Що в `Данные` | Де живе |
|---|---|---|
| `СМП_ОчередьОбработкиДанных` | `ЗначениеВСтрокуВнутр(Ссылка)` — посилання на документ/довідник | джерело |
| `СМП_ОчередьИсходящихСообщений` | JSON-рядок одного об'єкта | джерело |
| `СМП_ОчередьВходящихСообщений` | JSON-рядок, отриманий по HTTP | приймач |

Усі неперіодичні, незалежні. Спільні процедури — `CommonModules/СМП_ОнлайнОбменУправлениеОчередями`.

### РС СМП_ВыгруженныеСправочники

Виміри: `УчетнаяЗаписьОбмена`, `ЭлементСправочника` (Строка — `ЗначениеВСтрокуВнутр(Ссылка)`).
Факт «цей елемент довідника вже повністю надсилався цим обліковим записом» (див.
[05](05-konvertatsiya.md#довідники-вже-вивантажені)). Модуль менеджера:
`ЗарегистрироватьВыгрузкуЭлементовСправочников`, `ПроверитьВыгрузкуЭлементаСправочника`.

## Перелічення

| Перелічення | Значення | Використання |
|---|---|---|
| `СМП_СтатусыОбработкиСообщений` | Новое, ВОбработке, Доставлено, Отправлено, ОшибкаОбработки, ОшибкаДоставки, Обработано, ОшибкаОтправки | Статус у чергах. Реально встановлюються лише Новое, ВОбработке, Доставлено, Обработано, ОшибкаОбработки **[код]** |
| `СМП_НастройкиОбменов` | ДляОтправки, ДляПолучения | Напрям облікового запису |
| `СМП_ВидыТранспортовОбмена` | Файл, ХттпСервис, Ком | Транспорт |
| `СМП_ВидыПоказателейСверки` | Реквизит, Выражение | Вид показника правила звірки ([07](07-zvirka.md)) |
| `СМП_ВидыОбъектовОбмена`, `СМП_ВидыСвойств`, `ТипыОбъектов`, `Приложения`, `ПриоритетОбъектовОбмена` | — | Опис метаданих і правил, перенесені з КД2 |

| `Subsystems/СМП_ОнлайнОбменДанными` | Розділ інтерфейсу |
