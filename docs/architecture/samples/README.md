# Приклади

Реальні пакети й правила пари «УНФ → BAS Бухгалтерія», **знеособлені** (2026-10-01).

| Файл | Що це |
|---|---|
| `01-dovidnyk-nomenclatura.json` | Повне вивантаження елемента довідника (одне повідомлення вихідної черги) |
| `02-dokument-nadhodzhennya.json` | Документ `ПоступлениеТоваровУслуг` (одне повідомлення; довідники — лише посиланнями) |
| `pravula-unf-bp.xml` | Правила конвертації у форматі КД2, вивантажені з розширення (`ВыгрузкаКонвертацииXML`) |

Що замінено на умовне: назви товарів, ПІБ, коди ЄДРПОУ, назва клієнта, номери документів і
договорів, артикули, префікси номерів/кодів, назва складу, клієнтський префікс об'єктів
`АФ_` → `КЛ_`. GUID замінено **узгоджено** (`00000000-0000-4000-8000-…`): однакове посилання в
обох файлах має однаковий умовний GUID. Числа (суми, ціни, кількості, курси), дати, коди
класифікаторів (валюта 978, одиниця 2009, УКТЗЕД) і структура — без змін.

Тексти алгоритмів у `pravula-unf-bp.xml` лишились як є (крім замін вище) — вони відображають
логіку конкретного впровадження.
